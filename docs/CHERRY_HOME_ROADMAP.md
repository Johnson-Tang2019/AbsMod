# 1.21.1 后续开发方案

基线为 0.5.0 樱花家居，目标平台为 Minecraft 1.21.1 NeoForge。方案结合 11 月 18 日开发审查、当前源码和本轮家居实测。下列批次均为 **PROPOSED**，用来安排开发。0.6.0 将三个批次接入 1.21.1。下文保留原始规划，已实现的交互与验证证据以 [STATUS](STATUS.md) 为准。

## 0.6.0 首版规则（PROPOSED 数值）

铃铛点选自己已显现的剑灵，再点桌上指定的杯位。杯子到举杯结束才扣除，返还已有奶昔容器空桶；主人和访客都能取杯，邀请只属于剑灵主人。茶会使用当日交流额度。主人离桌、召回、卸载、取走或更换原杯都会取消，重新邀请即可。猫窝沿用 16 格寻路范围。心镜按普通八阶剑发起，不收门票，原地试炼限于镜旁；普通九阶沿用已有方案的 250 好感与 16 紫水晶块。数值仍待长期生存体验。

## 第一批：让剑灵赴一次茶约

玩家已经能摆好茶桌、落地灯和收纳柜，也能在奶昔茶盘上放四杯饮品。眼下最值得补的一步，是让主人放好一杯奶昔，邀请已经显现的剑灵进屋，一起完成一次看得见的互动。

- 先解决摆放。矮桌台面只有 9/16 格高，现有茶盘是独立方块。建议让玩家对桌面使用茶盘，将它装在桌上。沿用已有杯位、每杯物品组件和取回操作；拆桌时分别返还桌、盘和剩余饮品。首个原型先用现成的四杯模型。
- 玩家再用结缘铃点选自己的剑灵和已装杯的茶桌。剑灵走到可达的一侧、朝向主人并举杯。找不到路径或茶杯已被取走时，结束邀请并说明原因。每段互动只占用一个杯位，恢复逻辑复用现有剑魂记录与每日互动账本。
- 首批 FTB 任务建议为「摆好茶席」和「第一次赴约」。前者由茶盘正确放上矮桌完成，后者由服务端完成茶会后触发。先用原版进度跑通，再同步中文任务文本。
- **验收**：单人喝完一杯后其余三杯原样可取；两名玩家同时取杯或邀请同一剑灵，最多结算一次；移动、拆桌、召回或中途退出后，原剑、剑灵和杯子均可核对。0.6.0 的首版收支与权限见上方规则。

## 第二批：让猫真正使用已安置的家

以绒月猫窝为锚点，从观察手册选一只已记录的猫，在结缘铃上查看它最近一次回窝休息的记录。先做可观察的回窝、趴下和起身，再考虑樱花坐垫、抓板等新家具。沿用猫的身份、家谱与花色，不另建一份收藏数据。

- 单人先验证同一房间两只猫、两个窝的选择。独立服务器再分别卸载猫和猫窝所在的区块，验证重登、搬窝、他人访问及取回原窝。
- 界面区分「正在休息」「上次见于此处」与「当前未知」。FTB 的目标设为第一次实际完成回窝，而非要求玩家凑齐稀有毛色。寻路范围、休息间隔和是否出现偏好行为为 **TBD**。

## 第三批：从普通八阶走到九阶

这是当前喵刀主线的缺口。依照原审查的心镜方案，先制作一条可从头玩到尾的试炼，再扩充场地与表现。

1. 在现有共鸣界面显示原剑欠缺的条件。心镜读取主人、剑魂和阶段，为这把普通八阶剑建立一次挑战记录。
2. 先接入有明确预警的横斩、重落和收势窗口。以实际八阶装备测试可读性与攻击间隔，再确定心魔血量、伤害、门票和重试时间。
3. 胜利写入这把剑的持久记录；玩家带原剑回到共鸣工坊升九阶。FTB 分为「进入试炼」「通过心魔」「完成九阶共鸣」。
4. **验收**：用 A 剑通关后持 B 剑时显示 B 剑自己的资格；模拟双方玩家进入、战败、击杀瞬间断线和服务器重启。原剑的名称、附魔、耐久、好感与身份可核对，重复结算只得到同一把九阶剑。通过前保持生存八升九的既有门槛。普通线独立于暗黑八阶和粉色猫收藏。

## 各批次的交付办法

先在简体中文生存客户端完成一遍正常获取与使用，再测试本批特有的中断和多人情况。涉及剑魂或稀有展品转移时，记录操作前后各自持有的物品、身份和数量。实机截图、已通过和待验证项写入 STATUS。同步中英文手册、原版进度及稳定 ID 的 FTB 任务；可选联动须在独立服务端验证。通过后备份、安装到指定 1.21.1 实例并提交推送。

美术优先级随玩法安排。茶会先补杯子与手部动作，猫咪家园再补休息姿态，心魔试炼优先保证预警与收势清楚；暗黑各阶独立贴图可在试炼动作确定后分批绘制。
