# 家猫遗传与收集玩法

2026-11-01 / CAT-01 / GUIDE-01。CONFIRMED：用户授权由开发者选择有趣的真实杂交方向。选择家猫毛色遗传，保留原版驯服、喂鱼、跟随与繁殖冷却；不是野生猫科跨种杂交。

本批实现目标：两亲各传递一个等位基因、稳定保存基因与父母UUID、观察与配对预测、隐性稀释色收集。遗传机制参考 UC Davis Veterinary Genetics Laboratory：https://vgl.vetmed.ucdavis.edu/resources/cat-coat-color 。这是游戏简化模型，不是完整现实育种模拟，不加入健康/遗传病惩罚，不把毛色等同品种或性格。

首批采用常染色体隐性稀释 D/d：DD 或 Dd 为浓色，dd 为稀释色；每只猫另有可遗传的图案来源。后代分别从父母抽取一个 D/d，图案从双亲等概率选一个。图案选择是明确的游戏近似，不宣称完整模拟白斑、重点色或橘色的性连锁。先让玩家能观察隐性携带者、预测 dd 概率并建立谱系，再扩展更多真实位点。

美术边界：沿用原版猫形体与纹理；黑色→蓝灰的稀释外观可用原版蓝灰纹理。其他未配齐稀释贴图的图案保留原图，并在观察说明中明确基因已稀释、外观暂未区别，不能称为完整新美术。

玩法：使用猫咪观察手册右键查看，潜行右键选择第一只，再右键第二只显示稀释概率。普通右键空气阅读玩法指南。两只健康成年且已驯服的猫站立、喂鱼后按原版方式繁殖；本批不新增性别限制。图鉴进度奖励发现基因、繁育谱系幼猫和 dd 幼猫，不以运气门槛阻挡喵刀主线。
