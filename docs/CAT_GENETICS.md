# 家猫遗传与收集玩法

## 猫咪收藏与安置（PLAN-CAT-01、PLAN-HOME-01／02）

本轮按路线图接入观察手册收藏、家谱、绒月猫窝和结缘铃。具体配方、16 格范围与界面交互为可玩的首版原型。

- 用观察手册右键猫写入自己的收藏。潜行用手册对空气右键打开收藏，普通对空气右键仍打开说明。可叠加筛选毛色、花纹、眼色，切换所有记录或只看自家猫。经典外观从已观察到的变体归类，缺少组合特征的记录可用「经典外观」筛选。
- 点击收藏中的猫查看代数、基因、亲本和已观察的后代。点击已记录的亲属可逐代查看。未知亲本保留占位，UUID 只用于存档。观察手册对两只猫的原有配对预测继续可用。
- 绒月猫窝：工作台上排线、空格、线，中排三个白色羊毛，下排三个任意木板。放下后由放置者管理。先用主手结缘铃右键自家的驯服猫，再右键猫窝。空手右键请猫回窝，空手潜行右键解除。每窝一猫，每猫一窝；更换既有绑定会释放原关系。拆掉猫窝只清除关系。距离足够近且有路可达时，猫会步行靠近并坐下。
- 结缘铃：上排铜锭、粉红色染料、铜锭，中排铜锭、紫水晶碎片、铜锭，下排空格、线、空格。持铃对空气右键查看已观察自家猫、已显现剑灵和上次记录。潜行右键呼唤已选中的猫，也可在详情点击「呼唤」。只处理同维度 16 格内已加载且可达的自家猫，不传送或强制加载。附近已显现剑灵的详情允许通过现有权威服务召回，使用匹配虚化剑槽或记录的原槽。
- 收藏、铃铛选择和猫窝关联为世界存档中的玩家数据。猫窝保存位置及猫身份引用，猫咪实体按原版保存。铃铛可以重做，猫咪与位置记录属于玩家。非主人的观察记录不保存伙伴坐标，收藏中的历史观察可在猫离开后继续查看。
- 原版进度和两版 FTB 增加收藏筛选、家谱、猫窝绑定、附近呼唤四项可选任务。保留原任务 ID，共 37 项。26.2 使用原版进度与第 25–28 页手册。
- 绒月猫窝与结缘铃为本项目原创方块模型，用游戏内置羊毛、陶瓦、金块与紫水晶材质。浅粉包边、白软垫、猫耳、金色钟体与粉带由 JSON 组件建模。模型、物品角度与方块轮廓分别在仓库资源中可编辑。


## PLAN-LIFE-01 · 26.1.2 樱绒梳

樱绒梳配方为首版候选。用工作台把粉红色羊毛和白色羊毛放在同一行，白色羊毛下方两格依次放线、木棍。梳子可反复使用，主手拿它靠近自家驯服猫或已显现的剑灵，右键梳理。

- 猫会短暂转头、呼噜并出现爱心，保留原来的遗传、毛色和坐姿指令。
- 剑灵会短暂低头，耳尾摆动。距离超过 4 格时动作结束。回剑或退出世界时，旧实体和表现一起离开。动作状态不随存档保存。
- 剑灵梳理与普通交流共用同一份每日好感额度。当天首次有效交流或梳理加 1 点，之后仍可梳理并看到反馈。生鳕鱼继续走独立赠礼额度。两种互动记录可在结缘铃详情查看。
- 手册第 30 页与新增 FTB 任务「梳梳毛，理理发」提供配方和使用提示。任务接受自己的猫或已显现的剑灵。
- 梳子采用本项目原创猫爪形立体模型，复用原版羊毛、陶瓦、白桦木和砂岩材质。

## 已实现的简化遗传

三对独立常染色体位点，每一位点从两亲各抽取一个等位基因，随实体保存父母UUID与代数：
- D/d：DD、Dd浓色；dd稀释。
- B/b：BB、Bb黑色基底；bb巧克力基底；bb dd为淡紫。
- C/cs：CC、Ccs不表达重点色；cscs表达固定重点色纹理。

组合覆盖巧克力、淡紫、海豹重点、蓝重点、巧克力重点、淡紫重点。只对纯黑、蓝灰、暹罗来源提供六套新外观；其他图案仍继承全部位点但保持原图，并提示外观未配齐。来源图案由双亲等概率选一个，是游戏近似。不是新物种或真实品种模拟，不模拟橘色性连锁、肉桂等位基因、白斑、性别、疾病或体温驱动的毛色变化。

来源：UC Davis VGL [毛色综述](https://vgl.ucdavis.edu/resources/cat-coat-color)、[Brown](https://vgl.ucdavis.edu/test/brown-cat)、[Colorpoint](https://vgl.vetmed.ucdavis.edu/test/colorpoint-restriction)、[Dilute](https://vgl.vetmed.ucdavis.edu/test/dilute-cat)。位点关联参考真实遗传；创始携带率、图案抽样和固定纹理是游戏设计，不能当作现实育种建议。

## 观察与配对

书＋生鳕鱼合成观察手册（20页）。手持右键猫查看三个基因型、代数、来源和父母记录；潜行右键选择第一只，再右键16格内第二只显示dd、bb、cscs和三重隐性概率。配对预测基于基因，不保证图案来源适用。

两只Dd Bb Ccs每次有1/64（约1.56%）概率产生dd bb cscs；同组合纯合双亲可稳定传递。概率不累计保底。两只成年驯服猫站立、喂鱼后仍按原版繁殖，不新增性别限制或刷奖励系统。

四项新目标分别观察有谱系且来自受支持图案的bb、bb dd、cscs、dd bb cscs后代；可以同时解锁，重点色也可满足巧克力/淡紫基因目标。猫路线不阻挡喵刀成长。
