# 喵刀合成、成长与数值方案 v2

日期：2026-10-31。状态：**PROPOSED，供评审与后续原型使用，未写入配方或运行时数值。**

用户本次授权设计完整路线，不等于批准以下每个参数。普通粉白九阶、钻石剑起源；暗黑粉紫八阶、下界合金剑起源；好感参与成长、普通八升九需要心魔，沿用 CONFIRMED 设定。剑灵当前无敌、攻击召回，不重新加入死亡扣罚。九阶原画与现有物品 ID 保留。

## 1. 普通路线：从武器到伙伴

主循环：合成一阶 → 战斗与同行建立关系 → 收集阶段材料 → 在同一把剑上完成升阶 → 八阶挑战心魔 → 九阶共鸣。

阶段名称仅为显示名草案：初鸣、结缘、灵晶、月华、心契、羽梦、星辉、镜心、归一。保持同一个 soulId、主人与关系档案，不生成另一个器灵。暂不加入随机词条、失败碎剑、重复刷同一阶或强制每日任务。

## 2. 合成与升级材料

一阶采用无序合成：钻石剑 ×1、紫水晶碎片 ×4、生鳕鱼 ×1、粉红色染料 ×1。图案后续可调整；实现必须使用能保留输入剑数据的自定义配方，不能用普通静态结果 JSON 丢失附魔和名字。新剑首次获得身份仍由现有服务端身份服务负责。

升级拟采用独立的“共鸣”界面：放入原剑及材料，展示属性变化、好感门槛及未满足条件，主动确认一次。下面材料数量是每次升级的总量，不表示普通工作台的一格支持堆叠消耗。新界面与方块尚未实现，不假称原版锻造台能直接处理这些条件。

## 4. 好感成长

范围建议 0–300，初始 0；升级不消耗，不被单次伤害量放大。

- 有效同行：剑灵显现、同维度且距主人 16 格内；每累计 5 分钟活跃同行 +1，每游戏日最多 +4。挂机判定须使用玩家移动/互动证据，不只看在线时间。
- 互动：每游戏日首次有效交流 +1；合适礼物 +2，每日最多一次。不无限喂鱼刷满。
- 共同战斗：每 10 次有效敌对目标主命中 +1，每游戏日最多 +4；同一受困目标、友军、无伤害攻击不计。目标反刷细则需落地测试。
- 每游戏日合计最多 +11；最快达到 250 约 23 个游戏日、约 7.6 小时连续有效活动。该值是设计下界，不是承诺通关时间。

普通路线所有新门槛先做可配置原型。暗黑也需要关系成长，但门槛较低；不是复制普通连击层数作为好感。不给当前无敌剑灵编造死亡掉好感。

暗黑“代价”仍只确认八阶封顶，不擅自实装扣血、诅咒或掉经验。重击输入与上述精确参数均是本轮新提案。

## 6. 实施顺序与验收

先完成普通连击属性与动作同步验证，再实现身份安全升级事务，随后实现共鸣界面和材料消耗，最后接好感获取与心魔资格。普通九阶在心魔实现前仅保留管理员测试入口，不用临时配方绕过 Boss。

测试需覆盖同魂升级、附魔/命名/耐久迁移、满背包、断线、重复点击、两人同时操作、显现期间拒绝、材料不足不扣费、未通关不能升九阶。数值分别测无护甲与装甲目标、连续命中/移动/护盾、两玩家同时攻击和单位时间耐久。原始有效命中数据优先于纸面 DPS。
