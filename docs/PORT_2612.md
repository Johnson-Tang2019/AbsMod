# Minecraft 26.1.2 Fabric

Java 25。此目标按 Minecraft 26.1.2 独立构建，复用 26.2 Fabric 的共用逻辑、模型、贴图和数据，并为客户端界面访问、攻击指示器和世界渲染事件提供对应版本的适配。模组包名为 `absmod-fabric-0.1.0+26.1.2.jar`。

## 游玩与安装

使用 Minecraft 26.1.2 Fabric 和 [Fabric API 0.155.3+26.1.2](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.155.3%2B26.1.2/)。观察手册使用书和生鳕鱼合成，内有刀的配方、共鸣升阶、剑灵交接、战斗与猫繁育说明。普通路线目前可升至八阶，九阶等待同魂心魔。暗黑八阶封顶，重击默认 **G**。

显现自己的剑灵后，持结缘铃对空气右键，在列表点击剑灵查看当前阶段、好感差值、耐久、当日交流和生鳕鱼赠礼记录、活跃同行与战斗额度。每日记录以主世界的游戏日为准。点击「刷新」重新读取。手册第 29 页和 FTB 的好感任务有同样的操作指引。第 30 页和「梳梳毛，理理发」任务介绍樱绒梳的合成与使用。

在剑灵详情点「剑灵饰品」可以翻页浏览 12 款可合成的头饰。每款都用一份金粒、一份线和一个专用材料无序合成。把饰品放在背包里即可重复佩戴。手册第 31–33 页列出了操作和所有专用材料。

在「陪伴游戏」选择 3×3 井字棋、9×9 自由规则五子棋或 8×8 黑白棋，均由玩家先手。黑白棋用带点的格子提示合法落点，无处落子的一方自动跳过，终局按棋子数判胜。三款均可重开，完成任意结果的一局即触发对应原版进度和 FTB 任务。规则见手册第 34–35 页。

奶昔茶盘使用五块樱花木板、两块粉红色羊毛和一枚紫水晶碎片。工作台上排两端放木板，中排按羊毛、紫水晶碎片、羊毛排列，下排铺满木板。主手持任意一种奶昔右键空杯垫放入一杯。空主手点对应杯垫取回原瓶并完成「奶昔茶会」。茶盘可供访客取用，打破会掉出剩余奶昔。手册第 36–37 页有对应操作。

选择使用 FTB 时，将 [26.1.2 任务包](../quest-packs/ftb-26.1.2/README.md) 的 `config/ftbquests/quests/` 合并进实例。现有章节和语言键可保留。26.1.2 使用 JSON5 并对旧导出中的负数 ID 进行确定性映射。两个版本的任务对应同一游玩路线，分别保存进度。

## 构建与验证

```powershell
./gradlew.bat -p 26.1.2Fabric build
./gradlew.bat -p 26.1.2Fabric runGameTest -PgameTests
./gradlew.bat -p 26.1.2Fabric runClient -PportVisualTest
```

图形验证夹具仅在显式启用时生效。运行前把 FTB 文件放入该模块的 `run/mods`，把任务放入 `run/config`。测试会新建一次性世界，验证共鸣与收藏、剑灵饰品与三种棋局，并用客户端交互放置茶盘、摆入四款饮品和取回一杯。正式构建省略 `-PportVisualTest`。
