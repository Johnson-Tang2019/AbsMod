# Minecraft 1.21.1 NeoForge port / 版本适配

Task IDs: PORT-01 / GUIDE-02. See STATUS and PORT_1211_DELIVERY.json for actual checks and installed hashes.

## Build and source boundary

Run the existing root wrapper with JDK 25: `./gradlew.bat -p 1.21.1NeoForge build`.
The game uses Java 21; the compiler emits Java 21 bytecode/API (`--release 21`). The host compiler avoids a Java 21 worker argument-file failure in paths containing an apostrophe. Both client/server launch argument files quote those paths.

The independent ModDevGradle module compiles `common/src/minecraft1211/java` and its own platform events. This is an explicit version adaptation, not a binary dependency on Minecraft 26.2. Shared assets/data come from common; recipe ingredients and advancement backgrounds convert during resource processing. Future gameplay fixes must update both API branches; 26.2 Fabric/NeoForge continue building from common/src/main/java. No FTB Java classes are linked by the release mod; quests are optional configuration data.

1.21.1旧API适配包括实体NBT、SavedData、剑材质耐久、物品交互返回值、Component书页同步、Raycast、客户端RenderType/MultiBufferSource和玩家模型动画。独立客户端入口避免服务端加载模型类；保持Bedrock路线，没有替换为GeckoLib或YSM。

## FTB setup and repeatable fixtures

Official artifacts and SHA256: `1.21.1NeoForge/runtime-mods.json`. Fetch with `tools/quests/fetch_1211_dependencies.ps1`. Libraries remain in ignored run/mods and are not redistributed inside the Ab’s Mod JAR.

Regenerate the chapter with `python tools/quests/export_quests.py`; merge `quest-packs/ftb-1.21.1/config/ftbquests/quests` into the instance config. Back up the same chapter and merge only this pack’s keys into an existing zh_cn.snbt. Never replace unrelated chapters or world/team progress. FTB’s inline fallback remains for older 2101 packs; modern zh_cn translations are explicit.

Opt-in fixture: `./gradlew.bat -p 1.21.1NeoForge runClient -PportVisualTest`. It creates a fresh disposable flat world, drives progression and real packets, asserts outcomes, captures screenshots, then exits. Use only the development run directory. The fixture imports the optional FTB runtime jars as compile-only dependencies.

Dedicated fixture: point the development `run/server.properties` level-name to the previously completed fixture world, bind localhost, then `./gradlew.bat -p 1.21.1NeoForge runServer -PportVisualTest`. It checks restored quest progress and server-only gameplay, logs PORT_SERVER_PASS, and stops. Check for errors as well as Gradle status: exceptions scheduled on the server executor may be logged without causing a nonzero Gradle exit. Never run the fixture on a personal survival world.

## Actual validation

- Client: ordinary/dark upgrade, transaction replay rejection, retained damage ratio; heavy windup, 90 health loss exactly once, cooldown rejection; Chinese guide; 25 FTB quests with 7 completed before spirit tests; spirit appearance/projection and attack recall; sampled first-person motions, pink slash passes and reload (196 bones, no fallback).
- Dedicated server reload: 10 FTB quests restored; actual Cat offspring and entity NBT round-trip, stage durability, broken sword retained, soul identity across manifestation/recall, invulnerability and registered crafting recipe.
- Release: all classes Java 21; no visual/server fixture classes; JSON parsed; 17 spectral models; both 26.2 loader builds still pass.
- Not verified: PCL launcher button flow, 1.21.1 multiplayer latency, complete third-person pose matrix, every milkshake effect, survival balance or cross-version saves.
