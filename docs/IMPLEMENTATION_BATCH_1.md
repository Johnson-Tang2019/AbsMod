## 本次代码

- `BladeSoulReference` 自定义物品组件仅存 soul UUID，双加载器注册共享组件。
- `BladeSoulStore` 使用服务器全局 SavedData；`BladeSoulRecord` 保存 UUID、可选主人、路线、阶段、可选好感、修订、schema 版本和形态。schema 1 仅接受 sword；未来转换字段必须通过明确版本迁移加入。
- 显式管理员初始化；普通创建、查询、工具提示不分配身份。测试初始化记录目标玩家为主人，不是自动绑定机制。
- 好感初始为未设置；测试 set/add 只接受有限值。add 要求先设置；默认值、上下限、自动增长规则仍为 TBD。每次写入校验修订号。
- 缺失引用、不可读档案、未知 schema、无效记录及重复档案 UUID 拒绝读取或修改，不接受部分解码，不自动覆盖或重建。
- 测试命令检查在线物品重复身份；不自动换号。范围仅在线背包、末影箱、已加载掉落物，尚未覆盖离线玩家、容器、嵌套存储及全局战斗限制。
- 迁移接口只生成下一阶段方案，保留身份、主人、好感，使用目标默认属性；没有提交事务、升级配方或切换机制。其他组件复制策略仍待确认。
- 扩大粉色刀光半透明层：主光幕宽度参数 0.48 → 0.78、透明度系数 0.36 → 0.24；外晕宽度 0.55 → 0.88、透明度系数 0.24 → 0.16。保留亮芯和六种挥动方向。

## 验证范围

独立验证覆盖身份唯一性、只读查询、重复初始化、缺失记录拒绝、好感与修订检查、ItemStack NBT 和网络组件往返、迁移方案、无效及重复档案拒绝，以及实际 SavedDataStorage 写文件、关闭、重新打开读取。独立测试为了构造原版已冻结注册表中的物品，使用测试专用注册初始化；它不能证明加载器运行时注册事件已验收。

测试暴露了 Fabric 不接受空 DataFixTypes 的重载问题，现使用 SAVED_DATA_COMMAND_STORAGE 容器兼容原版读档；器灵记录格式仍由自己的 schema 校验管理。

双加载器构建结果以 STATUS.md 当前执行记录为准。尚未在游戏客户端或专用服务器执行验收；不得据此进入第二批器灵实体开发。
